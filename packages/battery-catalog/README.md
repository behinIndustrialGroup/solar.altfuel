# Battery Catalog Package

پکیج مدیریت جامع کاتالوگ باتری‌ها برای سیستم‌های ذخیره‌سازی انرژی خورشیدی

## ویژگی‌ها

- ✅ ثبت کامل مشخصات فنی باتری‌ها
- ✅ مدیریت انواع باتری (LiFePO4, Lithium-ion, Lead Acid, و غیره)
- ✅ ثبت ظرفیت انرژی و ولتاژ
- ✅ مدیریت مشخصات شارژ و دشارژ
- ✅ قابلیت توسعه و اتصال موازی
- ✅ مدیریت استانداردهای بین‌المللی باتری
- ✅ سیستم تاییدیه آزمایشگاه
- ✅ بارگذاری و مدیریت دیتاشیت PDF
- ✅ تایید اتحادیه با تاریخ تایید
- ✅ پشتیبانی از چندین پروتکل ارتباطی

## نصب

پس از آپلود فایل‌ها:

1. اضافه کردن namespace به `composer.json`
2. ثبت ServiceProvider در `bootstrap/providers.php`
3. اجرای `/setup-packages`

## استانداردهای پشتیبانی شده

- IEC 62619
- IEC 62620
- IEC 62133
- UN38.3
- CE
- UL1973
- IEC 63056 (برای باتری‌های ذخیره‌ساز)

## مسیرها

```
/admin/battery-catalog          → لیست باتری‌ها
/admin/battery-catalog/create   → فرم ایجاد
/admin/battery-catalog/{id}     → جزئیات
/admin/battery-catalog/{id}/edit → ویرایش
```

## تایید اتحادیه

باتری به صورت خودکار "تایید اتحادیه" می‌شود اگر:
1. تاییدیه آزمایشگاه داشته باشد
2. نام آزمایشگاه مشخص شده باشد
3. فایل دیتاشیت بارگذاری شده باشد
